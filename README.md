# 실시간 수면·졸음 감지 시스템

웹캠 영상에서 추출한 얼굴 특징의 시간적 변화를 분석하여
사용자의 수면·졸음 상태를 추정하고, 감지 이벤트를 기록하는
실시간 웹 애플리케이션입니다.

브라우저에서 MediaPipe를 이용해 얼굴 랜드마크를 추출하고,
EAR, MAR, Pitch 등의 수치 데이터를 서버로 전송합니다.
서버에서는 LSTM 모델로 연속된 특징 데이터를 분석하여 상태를 추정하고,
감지 결과를 웹 대시보드와 데이터베이스에 반영합니다.

또한 브라우저 기반의 자체 데이터 수집기를 개발하여,
AI 학습용 CSV 데이터셋 수집부터 전처리와 모델 학습까지
연결되는 데이터 파이프라인을 구축했습니다.

## 주요 기능

- 웹캠 기반 실시간 얼굴 랜드마크 추출
- EAR, MAR, Pitch 기반 얼굴 특징 계산
- 자체 데이터 수집기를 통한 AI 학습용 CSV 데이터셋 구축
- 슬라이딩 윈도우 기반 시계열 데이터 구성
- LSTM 기반 수면·졸음 상태 추정
- Socket.IO 기반 실시간 데이터 전송 및 상태 알림
- 수면·졸음 감지 이벤트의 시작 시간, 종료 시간, 지속 시간 및 판정 사유 저장
- 다크 테마와 글래스모피즘 스타일의 반응형 웹 대시보드

## 데이터 파이프라인

### 자체 데이터 수집기

별도의 외부 데이터 수집 도구 없이, 웹 브라우저에서 실행되는
자체 데이터 수집기를 개발했습니다.

웹캠 영상에서 MediaPipe로 얼굴 랜드마크를 실시간 추출하고,
이를 바탕으로 계산한 EAR, MAR, Pitch 등의 특징값을
AI 학습용 CSV 데이터셋으로 저장하는 과정을 자동화했습니다.

### 전처리 및 학습 데이터 구성

수집한 CSV 원시 데이터를 Pandas와 NumPy로 전처리하고,
슬라이딩 윈도우를 적용하여 연속된 프레임의 특징값을
LSTM 학습용 시퀀스 데이터로 변환합니다.

### 데이터 수집 및 모델 학습 흐름

웹캠 영상
→ 자체 데이터 수집기(data_collect.html)
→ MediaPipe 기반 얼굴 랜드마크 추출
→ EAR / MAR / Pitch 계산
→ AI 학습용 CSV 데이터셋 저장
→ Pandas / NumPy 기반 전처리
→ 슬라이딩 윈도우 기반 시퀀스 생성
→ PyTorch 기반 LSTM 모델 학습

## 설계 특징

### 1. 영상 대신 수치 데이터 전송

웹캠 영상이나 이미지 프레임을 서버로 전송하지 않고,
브라우저에서 추출한 EAR, MAR, Pitch 등의 수치 데이터만 전송합니다.

영상 분석은 클라이언트에서 수행하고, 서버는 전달받은 특징 데이터의
시계열 분석과 상태 추정에 집중하도록 역할을 분리했습니다.

이를 통해 서버 측 영상 처리와 원본 영상 전송이 필요하지 않은
경량화 파이프라인을 구성했습니다.

### 2. 시간적 패턴 기반 상태 추정

단일 프레임의 특징값만으로 상태를 판단하지 않고,
슬라이딩 윈도우로 구성한 연속 프레임의 특징 시퀀스를
LSTM 모델에 입력합니다.

눈의 개폐, 입의 벌어짐, 고개 각도가 시간에 따라 변화하는 패턴을
분석하여 수면·졸음 상태를 추정하도록 설계했습니다.

### 3. 데이터 수집부터 추론까지 연결된 구조

브라우저 기반 자체 데이터 수집기로 학습용 데이터를 구축하고,
전처리와 시퀀스 생성 과정을 거쳐 LSTM 모델을 학습합니다.

학습된 모델은 실시간 서비스에서 전달받은 얼굴 특징 시퀀스를
분석하는 데 사용됩니다.

데이터 수집, 모델 학습, 실시간 추론이 연결되는 구조로
프로젝트를 구성했습니다.

### 4. 실시간 양방향 통신

Socket.IO를 활용하여 클라이언트에서 계산한 특징값을 서버로 전송하고,
서버의 상태 추정 결과와 알림을 클라이언트로 전달합니다.

### 5. 감지 이벤트 기록

실시간 상태 표시와 별도로, 감지 이벤트의 시작 시간, 종료 시간,
지속 시간 및 판정 사유를 PostgreSQL에 저장하여
이벤트 이력을 확인할 수 있도록 구성했습니다.

## 실행 방법

### 1. 환경 설정
1. 저장소 클론: `git clone [저장소 URL]`
2. 클라이언트 환경 설정: `client/config.sample.js` 파일의 이름을 `config.js`로 변경하고, 사용 중인 ngrok 주소 등 서버 URL을 입력합니다.
3. 데이터베이스 설정: 서버 폴더에 `.env` 파일을 생성하고 PostgreSQL 접속 정보를 입력합니다.
4. 'client/index.html'파일의 196번째줄의 주소 또한 포워딩한 주소로 변경합니다.
