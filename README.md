## 프로젝트 개요

웹캠에서 추출한 얼굴 특징의 시간적 변화를 분석하여
사용자의 수면·졸음 상태를 추정하고, 감지 이벤트를 기록하는
실시간 웹 애플리케이션입니다.

영상 분석은 클라이언트에서 수행하고, 서버에는 영상 대신
EAR, MAR, Pitch 등의 수치 데이터만 전송하도록 설계했습니다.

## 기술 스택

### 1. AI / Machine Learning

| 기술 | 역할 |
| --- | --- |
| PyTorch | 딥러닝 모델 구현, 학습 및 추론 |
| LSTM | 프레임별 얼굴 특징의 시간적 패턴을 학습하여 수면·졸음 상태 추정 |
| Pandas / NumPy | CSV 데이터 전처리 및 슬라이딩 윈도우 기반 시퀀스 데이터 생성 |

### 2. Frontend

| 기술 | 역할 |
| --- | --- |
| HTML5 / CSS3 / Vanilla JavaScript | 반응형 웹 대시보드 구현 |
| MediaPipe Face Mesh | 웹캠 영상에서 얼굴 랜드마크 추출 |
| Socket.IO Client | 얼굴 특징 데이터 전송 및 서버의 상태·알림 수신 |

얼굴 랜드마크를 바탕으로 다음 특징을 계산합니다.

- EAR (Eye Aspect Ratio): 눈의 개폐 상태를 나타내는 비율
- MAR (Mouth Aspect Ratio): 입의 벌어짐 정도를 나타내는 비율
- Pitch: 고개가 위아래로 기울어진 각도

UI에는 다크 테마와 글래스모피즘 스타일을 적용했습니다.

### 3. Backend

| 기술 | 역할 |
| --- | --- |
| Python | 데이터 처리 및 서버 비즈니스 로직 구현 |
| python-socketio | ASGI 기반 실시간 양방향 이벤트 통신 |
| Uvicorn | ASGI 애플리케이션 실행 |
| SQLAlchemy | ORM 기반 데이터베이스 접근 및 이벤트 저장 |
| python-dotenv | 데이터베이스 연결 정보와 모델 설정 등 환경변수 로드 |

### 4. Database

| 기술 | 역할 |
| --- | --- |
| PostgreSQL | 수면·졸음 감지 이벤트 저장 |

저장 항목:
- 이벤트 시작 시간
- 이벤트 종료 시간
- 지속 시간
- 판정 사유

### 5. Infrastructure & Collaboration

| 기술 | 역할 |
| --- | --- |
| ngrok | 로컬 서버의 외부 접근 및 HTTPS 기반 개발·시연 환경 제공 |
| Git / GitHub | 소스 코드 버전 관리 및 협업 |

## 시스템 구조

웹캠 영상
→ 브라우저에서 MediaPipe로 얼굴 랜드마크 추출
→ EAR / MAR / Pitch 계산
→ Socket.IO로 수치 데이터 전송
→ 서버에서 시퀀스 구성 및 LSTM 추론
→ 감지 상태를 클라이언트에 전달하고 이벤트를 PostgreSQL에 저장

## 설계 특징

### 영상 대신 수치 데이터 전송

웹캠 영상 및 이미지 프레임을 서버로 전송하지 않고,
브라우저에서 추출한 얼굴 특징값만 전송합니다.

이를 통해 서버 측 영상 처리와 영상 전송이 필요하지 않도록
처리 구조를 분리했습니다.

### 시간적 패턴 기반 상태 추정

단일 프레임의 특징값만 사용하는 대신,
슬라이딩 윈도우로 구성한 연속 프레임의 특징 시퀀스를
LSTM에 입력하여 시간에 따른 변화를 분석합니다.
